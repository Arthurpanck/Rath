# Cahier des charges — Widget « Tableau de bord » pour Grist (ECharts)

- `Cahier_des_charges_Widget_Dashboard_Grist_ECharts.docx` — le cahier des charges (23 pages) ; la version PDF est à côté.
- `maquette-widget-dashboard.html` — la maquette utilisée pour les captures. Ouverte seule, elle affiche des données d'exemple ;
  installée comme widget personnalisé Grist (accès « document complet »), elle lit les tables `Projets` et `Demandes`.
  Ajouter `#edit`, `#picker` ou `#dark` à l'URL pour voir le mode édition, le sélecteur de tuiles ou le mode sombre.
